# 🎓 مولّد الشهادات (Next.js)

ارفع ملف Excel فيه أسماء المشاركين، صمّم الشهادة، ونزّل شهادة PDF لكل واحد دفعة وحدة.

## التشغيل

```bash
npm install
npm run dev
```

وافتح http://localhost:3000

## شو بيعمل المشروع؟

1. **رفع ملف** Excel أو CSV فيه عمود "الاسم" (واختياري: "الإيميل" و"الدورة").
2. **تصميم الشهادة**: 3 قوالب، تغيير اللون، لوغو، وتعديل كل النصوص.
3. **معاينة مباشرة** لكل مشارك (السابق / التالي).
4. **تنزيل**: ملف ZIP فيه PDF لكل شخص، أو PDF واحد فيه كل الشهادات للطباعة.
5. **رقم شهادة** تلقائي لكل واحد (CERT-2026-0001 ...).

بالمجلد `public` في ملف مثال `sample-participants.xlsx` تجرّب فيه.

## هيكل المشروع

```
app/
  layout.js            ← الصفحة الأم: اتجاه RTL وخط Cairo
  page.js              ← الصفحة الرئيسية: بتجمع كل المكونات وبتمسك الـ state
components/
  FileUpload.js        ← رفع الملف (سحب وإفلات)
  SettingsForm.js      ← فورم إعدادات الشهادة
  CertificatePreview.js← المعاينة على canvas
lib/
  drawCertificate.js   ← رسم الشهادة والقوالب (هون بتضيف قوالب جديدة)
  parseFile.js         ← قراءة Excel/CSV
  generatePdfs.js      ← تحويل الشهادات لـ PDF و ZIP
```

## ليش بنرسم على canvas بدل ما نكتب على الـ PDF مباشرة؟

مكتبات PDF بالمتصفح ما بتعرف توصل الحروف العربية ببعض صح. فبنرسم الشهادة على
canvas (المتصفح بيعرف العربي منيح)، وبعدين بنحط الصورة بصفحة PDF.

## كل الشغل بيصير بالمتصفح

ما في سيرفر ولا قاعدة بيانات، والملفات ما بتطلع من جهاز المستخدم. هاد بيخلي
المشروع سهل تنشره على Vercel ببلاش.

## خطوات جاية تتعلم منها

- [ ] **سحب النصوص وتحريكها** على الشهادة بالماوس.
